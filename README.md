# Тестовое задание в компанию "Вычислительные решения" на позицию Frontend-developer

Выбранный стек:
- Vue 3 (Composition API)
- TypeScript
- Jest

## Запуск

### Чтобы запустить проект локально следуйте следующим шагам:

#### 1. Установка требуемых зависимостей

```bash
npm i
```

#### 2. Компиляция и запуск в режиме разработки

```bash
npm run dev
```

#### Компиляция и запуск в режиме продакшн (опционально)

```bash
npm run build
```
